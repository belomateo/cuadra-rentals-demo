# Cuadra · Rentals (demo)

Sistema de gestión para rentals de esquí y snowboard: reservas por grupo, stock en vivo por número de tabla, taller, garantías, caja, clientes, equipo e integraciones.

**Ver la demo:** https://belomateo.github.io/cuadra-rentals-demo/

- Es una demo con **datos de ejemplo** de un rental inventado. Ningún nombre ni número es real.
- Funciona en la compu, la tablet y el celular. No hay que instalar nada.
- Para ver lo que le toca a cada puesto, elegí Mostrador o Taller en «Ver como».
- Arriba se puede buscar o escanear el número de una tabla.
- Lo que cambies queda guardado solo en tu navegador. «Volver a los datos de ejemplo» lo reinicia.
